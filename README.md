# MECH v0.52

Upload these extracted files directly to your GitHub repository root. Do not upload the ZIP itself.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). No build step or dependencies are needed. Keep the assets folder and all game files together.

Open the Pages URL on iPad, press STORY MODE to enable audio, and let the first online visit finish caching before playing offline. Add to Home Screen for the full-screen experience. Local saves remain on each device.

This package contains only the current playable game, its required local artwork/audio, this guide, and a checksum manifest. It excludes hosting credentials, Git history, old previews, source recordings, development scripts, test renders and replaced assets.

The game includes the story opening, workshop and guided tutorial; later campaign missions are not yet implemented.
